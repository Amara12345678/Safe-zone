# 🆘 SafeSignal (SafeZone) Гэр Бүлийн Апп

Энэхүү апп нь гэр бүлийн гишүүдийн хооронд SOS яаралтай тусламжийн дохио, байршил илгээх болон гар утасны сэрүүлэг дуугаргах зориулалттай систем юм.

## 📥 Шинээр татаж авсан хүн хэрхэн ажиллуулах вэ?

Энэхүү төсөл нь **React Native (Expo)** мөн custom native modules (`react-native-firebase`) ашигласан тул энгийн Expo Go дээр шууд ажиллахгүй. Дараах зааврын дагуу ажиллуулна:

### 1-р алхам: Шаардлагатай программ суулгах
Таны компьютерт дараах зүйлс суулгагдсан байх шаардлагатай:
* [Node.js](https://nodejs.org/en/) (v16 буюу түүнээс дээш)
* [Git](https://git-scm.com/)
* Android Studio (Android дээр ажиллуулах бол) эсвэл Xcode (iOS дээр ажиллуулах бол)

### 2-р алхам: Кодоо татаж аваад санг суулгах
Terminal эсвэл Command Prompt (CMD) нээгээд дараах командыг бичнэ:
```bash
# 1. Төслийг татах
git clone https://github.com/Amara12345678/SafeZone.git

# 2. Хавтас руугаа орох
cd SafeZone

# 3. Шаардлагатай сангуудыг суулгах
npm install
```

### 3-р алхам: Firebase нууц файлуудыг нэмэх (⚠️ АНХААР)
Аюулгүй байдлын үүднээс Firebase-ийн аюулгүйн тохиргооны файлууд GitHub дээр тавигдаагүй.
Энэ төслийг ажиллуулахын тулд апп-ын эзэмшигчээс (Amara12345678) доорх 2 файлыг авч, төслийн **үндсэн хавтас дотор** (`SafeZone/`) хуулж тавих ёстой:
1. `google-services.json` (Android-д зориулсан)
2. `GoogleService-Info.plist` (iOS-д зориулсан)

*(Эдгээр файлууд байхгүй тохиолдолд апп ажиллахгүй алдаа заах болно!)*

### 4-р алхам: Апп-ыг ажиллуулах
Төсөл саяхан Firebase Native модуль оруулж тохируулагдсан тул `run:android` комманд ашиглан Build хийж ажиллуулна.

**Android утсан дээр (эсвэл Emulator) ажиллуулах:**
```bash
# Энэ нь дотроо native хавтас үүсгээд аппаа шууд утсан дээр угсарч суулгана
npx expo run:android
```

**iOS дээр (Mac компьютертэй байх шаардлагатай):**
```bash
npx expo run:ios
```

## 🛠 Хөгжүүлэлтийн горим (Development Build - EAS)
Хэрэв та утас руугаа Development Build APK татаж аваад wifi-гаар холбогдож (Expo Dev Client) ажиллуулахыг хүсвэл:
```bash
# 1. EAS суулгах
npm install -g eas-cli

# 2. Expo дээр нэвтрэх 
eas login

# 3. Өөрийн төсөл рүүгээ build угсрах
eas build --profile development --platform android
```
Үүсч дууссаны дараа Expo-оос өгөх линкээр орж APK-г утсандаа татаж суулгана. Дараа нь код дээрээ `npx expo start` гэж уншуулаад гарч ирсэн QR кодыг утсаараа уншуулж холбогдоно e. 4/26/2026
