# 🆘 SafeSignal (SafeZone) Гэр Бүлийн Апп

Энэхүү апп нь гэр бүлийн гишүүдийн хооронд SOS яаралтай тусламжийн дохио, байршил илгээх болон гар утасны сэрүүлэг дуугаргах зориулалттай систем юм.

## 📥 1. Кодыг татаж авах болон ажиллуулах заавар

Энэхүү төсөл нь **React Native (Expo)** мөн custom native modules (`react-native-firebase`) ашигласан.

### 1.1 Шаардлагатай программ суулгах
Таны компьютерт дараах зүйлс суулгагдсан байх шаардлагатай:
* [Node.js](https://nodejs.org/en/) (v16 буюу түүнээс дээш)
* [Git](https://git-scm.com/)

### 1.2 Кодоо татаж аваад санг суулгах
Terminal эсвэл Command Prompt (CMD) нээгээд дараах командыг бичнэ:
```bash
# 1. Төслийг татах
git clone https://github.com/Amara12345678/Safe-zone.git

# 2. Хавтас руугаа орох
cd "Safe-zone"

# 3. Шаардлагатай сангуудыг суулгах
npm install
```

### 1.3 Firebase нууц файлуудыг нэмэх (⚠️ АНХААР)
Аюулгүй байдлын үүднээс Firebase-ийн аюулгүйн тохиргооны файлууд GitHub дээр тавигдаагүй.
Энэ төслийг ажиллуулахын тулд апп-ын эзэмшигчээс доорх 2 файлыг авч, төслийн **үндсэн хавтас дотор** хуулж тавих ёстой:
1. `google-services.json` (Android-д зориулсан)
2. `GoogleService-Info.plist` (iOS-д зориулсан)

*(Эдгээр файлууд байхгүй тохиолдолд апп ажиллахгүй алдаа заах болно!)*

### 1.4 Апп-ыг ажиллуулах
Төсөл нь Firebase Native модуль ашигладаг тул дараах байдлаар ажиллуулна:

**Android утсан дээр (эсвэл Emulator) ажиллуулах:**
```bash
npx expo run:android
```

## 🛠 2. EAS ашиглаж APK файл (Android) гаргаж авах заавар

Хэрвээ та кодоо өөрчлөөд бусдад суулгах зориулалттай жинхэнэ `.apk` файл гаргаж авахыг хүсвэл Expo Application Services (EAS) ашиглана.

### 2.1 EAS CLI суулгах болон нэвтрэх
```bash
# 1. EAS үйлдлийн системийг глобал байдлаар суулгах
npm install -g eas-cli

# 2. Expo-д нэвтрэх (Урьдчилан expo.dev дээр бүртгүүлсэн байх шаардлагатай)
eas login
```
*Энэ үед танаас Username (мэйл хаяг) болон Password нэхэх бөгөөд өөрийн Expo хаягаараа нэвтэрнэ.*

### 2.2 APK файл (Суулгах хувилбар) үүсгэх
Доорх командыг ажиллуулснаар аппликейшн Expo-ийн сервер дээр уншигдаж APK файл үүснэ.
(Хэрвээ анх удаа хийж байвал Android keystore үүсгэх үү гэхэд `Y` буюу Yes гэж дарна):
```bash
eas build -p android --profile preview
```
*(Жич: Танай төслийн `eas.json` дотор preview гэж байхгүй бол шууд `eas build -p android` гэж бичээд гарч ирэх сонголтоос APK гаргахаа сонгож болно)*

### 2.3 APK файлыг татаж авах
Build амжилттай дууссаны дараа Terminal дээр татаж авах **линк (URL)** гарч ирнэ. 
* Тэр линкийг хуулж аваад гар утасныхаа хөтөч (Browser) дээр нээхэд шууд `.apk` файл татагдах болно.
* Эсвэл өөрийн компьютероос [expo.dev](https://expo.dev/) хаягаар нэвтрэн орж төслийнхөө **Builds** цэснээс Install товчийг дарж татах боломжтой.
* Татаж авсан файлаа утсан дээрээ суулгаад хэвийн ашиглана.

## 📱 3. Хөгжүүлэлтийн горим (Development Build - Expo Dev Client)
Хэрэв та утас руугаа Development Build татаж аваад Wi-Fi-аар холбогдож код бичихдээ шууд утсан дээрээ өөрчлөлтөө харахыг хүсвэл:
```bash
eas build --profile development --platform android
```
Үүсч дууссаны дараа өгөгдсөн линкээр APK-г утсандаа татаж суулгана. Дараа нь код дээрээ:
```bash
npx expo start
```
гэж ажиллуулаад гарч ирсэн QR кодыг утсаараа (Expo Go биш, өөрийнхөө сая татаж суулгасан Development Build апп дотроос камер нээж) уншуулж холбогдоно.

## 🚀 4. App Store болон Play Store-д байршуулах (Publishing)

Энэхүү аппликейшн нь **Expo Application Services (EAS)** ашиглан Apple App Store болон Google Play Store-д шууд байршуулах (submit хийх) бүрэн боломжтой.

### 4.1 EAS Submit ашиглах
EAS нь таны үүсгэсэн (build хийсэн) файлыг дэлгүүрүүд рүү автоматаар илгээх хялбар шийдлийг санал болгодог. Үүний тулд:

```bash
# Play Store-д байршуулах
eas submit -p android

# App Store-д байршуулах
eas submit -p ios
```

### 4.2 Шаардлагатай зүйлс
Дэлгүүрт албан ёсоор байршуулахын тулд дараах зүйлс шаардлагатай:
1. **Хөгжүүлэгчийн эрх**: Apple Developer Account (iOS) болон Google Play Developer Account (Android) нээсэн байх.
2. **Сертификатууд**: EAS Build ашиглан Production build хийх үед автоматаар үүсэх сертификатуудыг (keystore, provisioning profile) ашиглах эсвэл өөрийнхийгөө оруулах.
3. **Тохиргоо**: `app.json` файл дотор `bundleIdentifier` (iOS) болон `package` (Android) нэршил, хувилбарын дугаар зөв тохируулагдсан байх.

Дэлгэрэнгүй зааврыг [Expo EAS Submit албан ёсны баримт](https://docs.expo.dev/submit/introduction/)-аас харах боломжтой.
